# Sotto brand

## Mark: decrescendo

Sound bars fading left to right into a red record dot — *sotto voce*,
"getting quieter". The red dot doubles as the recording state indicator:
in the menu bar it lights up while a recording is running.

Rules:
- The dot is the only colored element. Red is for recording state, never decoration.
- Monochrome contexts (menu bar): use `assets/menubar-template.svg` — macOS
  tints template images automatically.
- Don't rotate, outline, or add effects to the mark.

## Palette

| Name   | Hex       | Use |
|--------|-----------|-----|
| Ink    | `#1C1B22` | primary surfaces (dark), text on light |
| Paper  | `#F6F4EF` | primary surfaces (light), text on dark |
| Record | `#E5484D` | record dot, recording state only |
| Hush   | `#8A8699` | secondary text, timestamps |
| Accent | `#6C63D2` | links, interactive states |

## Typography

- App UI: system font (SF Pro) — native macOS feel.
- Wordmark and web: lowercase `sotto`, medium weight, slight letter-spacing.
  Free substitute: Inter.

## Voice

Short, quiet, lowercase. "no cloud. no drivers. yours."
